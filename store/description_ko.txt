[제목]
zz파워+ - 파워, 파워존, NP, 존별 시간, 운동 형태

[소개글]
3초 파워와 파워존을 크게 표시하고, 기록하는 동안 7개 존별 시간 비율을 히스토그램으로 보여주는 데이터 필드입니다.
넓고 높은 칸에서는 지금까지의 존별 시간을 분석해 어떤 형태의 운동인지(SST, VO2MAX, 양극화 등)를 함께 표시합니다.
가독성 향상을 위해 TitilliumWeb 폰트를 사용하여 제작되었습니다.
기존 zz파워차트를 새로 만든 앱입니다.

- 파워미터가 필요합니다. 휴대폰 연결은 필요 없습니다.
- 설정에서 FTP를 꼭 입력해 주세요. 파워존, IF, TSS 계산에 씁니다.

[파워와 파워존]
- 현재 파워를 칸을 꽉 채우는 큰 숫자로 표시합니다. 순간 / 3초 평균(기본) / 10초 평균 중에서 고를 수 있습니다.
- 1000W 이상은 1.25 kW처럼 표시해 큰 글씨를 그대로 유지합니다.
- 번개 옆에 현재 파워존(1~7)을 존 색으로 크게 표시합니다. 4.3처럼 존 안의 위치까지 소수로 볼 수도 있습니다. (설정)
- 오른쪽 위에 평균(기본), 최대, 랩 평균, NP, IF, TSS 중 하나를 함께 표시합니다. (없음 선택 가능)
- 맨 아래 7존 색 띠 위의 화살표가 지금 파워의 위치를 가리킵니다.

[NP · IF · TSS · 랩]
- NP: 30초 이동평균으로 계산합니다. 페달을 멈춘 0W도 포함하고, 일시정지 시간은 뺍니다.
- IF = NP ÷ FTP, TSS = 시간 × IF² × 100
- 랩 평균: 랩 버튼을 누를 때마다 새로 시작합니다. (가민과 같은 방식)

[존별 시간 히스토그램]
- 타이머가 도는 동안의 시간을 7개 존별로 모아, 전체 기록 시간 중 각 존이 차지하는 비율(%)을 막대로 표시합니다.
- 일시정지와 자동 일시정지 시간은 빠집니다.
- 넓고 높은 칸에서는 막대 위에 비율(%)을 숫자로 표시합니다.
- 막대 모양은 줄무늬(숫자가 잘 보임) 또는 채움 중에서 고를 수 있습니다.
- 라이딩 중에 앱이 다시 켜져도 존별 시간이 이어집니다.

[운동 형태 판정]
- 넓고 높은 칸(1필드, 2필드 등)에서 위쪽 절반에 파워와 보조값, 아래쪽 절반에 히스토그램을 표시합니다.
- 기록이 10분을 넘으면 존별 시간을 바탕으로 운동 형태를 파워 바로 아래에 표시합니다.
  예) SST - 스윗스팟
- 13가지: POL 양극화, RACE 레이스 페이스, BALANCE 자유 라이딩, SPRINT 스프린트, TABATA 타바타, HIIT 짧은 고강도 인터벌, VO2MAX 최대산소 인터벌, SST 스윗스팟, TEMPO 템포, FATMAX 장거리 지방 연소, BASE 베이스, RECOVERY 회복 라이딩, EASY 일상 라이딩
- 판정은 넓고 높은 칸에서만 10초마다 하므로 다른 칸에서는 배터리를 쓰지 않습니다. 설정에서 끌 수 있습니다.

[색상 표시]
- 보조값(평균 등)보다 기준(%) 이상 높거나 낮으면 현재 파워의 색을 바꿉니다. 높을 때와 낮을 때 색을 따로 고를 수 있습니다.
- "파워존 색"을 고르면 현재 파워를 항상 존 색으로 표시합니다.
- 배경색은 기기 설정(흰색 / 검정)을 따릅니다. 설정에서 세 가지 중에 고를 수 있습니다.
  기기 화면색에 맞춤(기본) / 검정·흰색 그대로 / 투명 - 투명은 배경을 칠하지 않아 기기 배경이 그대로 비칩니다.
  Edge 1050·1060에서 데이터 필드 배경이 다른 화면과 조금 달라 보이면 투명으로 바꿔 보세요.

[파워존 계산]
- FTP로 계산: Coggan(55/75/90/105/120/150%, 기본) 또는 Stages(59/79/90/104/120/150%)
- 1존부터 6존까지 최대 파워를 직접 입력할 수도 있습니다.

[칸 크기에 맞춘 자동 배치]
- 10칸 레이아웃의 한 칸: 위쪽에 번개, 존 번호, 보조값, 아래쪽에 현재 파워를 크게 표시합니다.
- 가로로 넓은 칸: 위쪽에 zzPowerPlus 제목과 표시 중인 값(AVG / MAX / LAP / NP / IF / TSS), 아래쪽에 두 값을 같은 크기로 나란히 표시합니다.
- 넓고 높은 칸: 운동 형태 화면 (설정에서 끄면 넓은 칸 화면)
- zz심박수+, zz속도+, zz케이던스+ 등과 같은 글꼴, 같은 크기, 같은 배치를 사용해 함께 쓰면 화면이 일관되게 보입니다.

[기록]
- 현재 파워존을 활동 기록에 함께 저장해 Garmin Connect에서 그래프로 볼 수 있습니다.
- 존별 시간 비율(%)을 활동 요약에 저장합니다.

[지원 기기]
Edge 540 / 550 / 840 / 850 / 1040 / 1050 / 1060

설정은 Garmin Connect IQ 앱 또는 Garmin Express에서 변경할 수 있습니다.
